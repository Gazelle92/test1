디자인 시스템 추출기

레퍼런스 사이트를 직접 측정해서 색·글꼴·간격·모서리·버튼·움직임을 숫자로 뽑고, 역할(배경·본문·강조…)과 "하지 않는 것"까지 초안으로 정리합니다. 초안은 사람이 시그니처와 쓰임새를 판단해서 다듬는 출발점입니다.

1. 레퍼런스에서 측정

  1. 레퍼런스 사이트를 열고 쿠키 배너·팝업을 닫습니다(동의는 하지 않아도 됩니다).
  2. 개발자 도구 콘솔(F12 → Console)에 스크립트를 붙여 넣습니다.
  3. DSX.collect() — 지금 페이지 측정. 다른 페이지(목록·상세·소개)로 옮겨 다시 붙여 넣고 DSX.collect()를 반복하면 쌓입니다. 모바일 폭(375)도 한 번 재면 좋습니다.
  4. DSX.report()로 콘솔에서 요약 확인 → DSX.json()을 실행하면 결과가 복사됩니다.

또는 북마크바에 끌어다 놓고 레퍼런스 페이지에서 누르기: DSX 불러오기
(사이트 보안 설정에 따라 막힐 수 있어요. 그때는 콘솔에 붙여 넣기)
