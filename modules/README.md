# 모듈 규칙

여러 사이트에서 가져온 섹션을 한 페이지에 섞어 쓰기 위한 규칙입니다.

## 구조
- `engine/` — 공통 엔진. 스크롤(Lenis)·GSAP·ScrollTrigger를 페이지에 하나만 둡니다.
- `engine/themes.js` — 테마. 디자인 토큰(글꼴·색·모서리)과 모션 토큰(이징·속도 배율·스크롤 설정)을 담습니다.
- `modules/{이름}/` — 섹션 하나 = 모듈 하나 (`index.js` + `style.css`).
- `pages/{이름}/page.js` — 조합 페이지. 모듈 순서·내용·기본 테마만 적습니다.

## 모듈이 지킬 것
1. `index.js`는 다음 값을 내보냅니다.
   - `id`, `category`(분류), `source`(참고한 곳)
   - `defaults`(바꿀 수 있는 내용)
   - `render(content)`(HTML)
   - `animate(el, m)`(움직임)
2. 스크롤을 직접 만들지 않습니다. Lenis를 새로 띄우거나 스크롤 이벤트를 따로 걸지 않습니다.
3. 글꼴·색·모서리 값을 직접 쓰지 않습니다. `var(--font-display)`, `var(--c-accent)`, `var(--radius)` 같은 토큰만 씁니다.
4. 이징·길이·순차 간격 값을 직접 쓰지 않습니다. 아래 도구를 씁니다.
   - 이징: `m.ease.out` / `inOut` / `back` / `elastic`
   - 길이: `m.d(초)`
   - 순차 간격: `m.stagger(초)`
   - 스크롤 연동: `m.scrub`
   - 단, 스크롤에 직접 묶인 움직임(scrub)은 `ease: "none"`을 씁니다.
5. CSS는 `[data-module="id"]` 아래로만 씁니다. 다른 모듈에 영향을 주지 않기 위해서입니다.
6. 원본 사이트의 이미지·문구·상용 글꼴은 넣지 않습니다. 구조와 움직임만 새 코드로 다시 만듭니다.
7. 섹션 위아래 여백은 `var(--space-section)`을 씁니다. 어떤 순서로 붙여도 간격이 같아집니다.
8. 배경·글자색은 `--c-bg`·`--c-fg`(와 `--c-surface`·`--c-line`·`--c-muted`)만 씁니다. 조합할 때 섹션마다 기본·반전 배경을 고를 수 있습니다.
9. 반응형 기준점은 768px 하나입니다. CSS는 `@media (max-width:767px)`, JS는 `m.mobile()`을 씁니다.
10. 새 모듈은 `modules/index.js` 목록에 한 줄 추가하면 창고에 나타납니다. `form`(스크롤형·고정형)과 `summary`(한 줄 설명)를 적습니다.

## 원본 섹션 (내부 참고용)
- 복제한 사이트의 섹션 25개를 원본 그대로 창고에 넣었습니다. 목록은 `clones/catalog.js`에 있습니다.
- 원본 조립 페이지: `/pages/compose/?list=jeskojets/01-hero,madewithgsap/05-pricing,m:pricing-flip`
  - `m:`을 붙이면 다시 만든 모듈입니다. 원본과 섞어 쓸 수 있습니다.
  - 섹션마다 원본 앱을 그대로 띄우고, 바깥 스크롤 하나가 각 섹션 안 스크롤을 대신 움직입니다. 그래서 원본 스크롤 효과가 그대로 동작합니다.
- 무드(`engine/compose.js`의 `MOODS`)는 원본을 고치지 않고 위에 얹기만 합니다.
  - 무드로 바꿀 수 있는 것: 글꼴 통일, 색 보정(filter), 스크롤 감도
- 매니저 창고에도 올라갑니다(`npm run build:library`). 원본 앱 파일·막힌 파일은 hm-office가 원본 서버에서 대신 받아 옵니다.
- 조립 화면에서 레퍼런스 이미지를 올리면 무드를 만들어 줍니다. 매니저에서는 AI가, 내 컴퓨터에서는 이미지 평균 색으로 간이 분석합니다.
- 강도 막대로 원본 무드 쪽으로 덜 바꿀 수 있습니다.
- 고객 결과물로 낼 때는 원본 사진·문구·유료 글꼴을 바꿔야 합니다.

## 창고·조합
- 모듈 창고: `/pages/library/`
  - 분류별로 보고 조합에 담습니다.
  - 순서와 배경(기본·반전)을 정합니다.
  - `page.js` 코드를 복사합니다.
- 바로 미리보기: `/pages/preview/?list=hero-window,effects-cards:alt&theme=pop`
